# Remote Web UI Icons

The PWA requires two icon files:
- `icon-192.png` (192x192 pixels)
- `icon-512.png` (512x512 pixels)

These should be the Mithium Sound app icon in PNG format.

For now, placeholder icons can be created by copying the main app icon from `build/icon.png` and resizing it, or by using any simple icon until proper PWA icons are created.

The icons should match the app's branding and theme (dark theme with the Mithium Sound logo/identity).
