How to create a Discord bot
  1. Go to the Discord Developer Portal (discord.com/developers/applications)
  2. Click New Application, give it a name, and click Create
  3. Go to the Bot tab on the left sidebar
  4. Your bot token is shown once after creation — click Copy to copy it and paste it below. If you missed it, click Reset Token to generate a new one
  5. Scroll down and enable Privileged Gateway Intents:
    • SERVER MEMBERS INTENT
    • MESSAGE CONTENT INTENT
  6. Go to OAuth2 > URL Generator on the left sidebar
  7. Under Scopes, check bot
  8. Under Bot Permissions, check Connect and Speak
  9. Copy the generated URL at the bottom and open it in your browser to invite the bot to your server
Advanced: Override bundled tools

yt-dlp and FFmpeg are bundled with the app. Only change these if you want to use a different version.

When no clip is loaded from the phone, V and T still control the clip you arm with 🎯. With this box on, hold V or T to play and release to stop. With it off, a tap of V or T plays that armed clip. When the phone has loaded a clip, V and T play that clip instead: one press plays it through. Auto-hold (on by default, switched on the phone) also holds the real V or T key down until the clip ends. When the clip finishes on its own, it unloads, so the next V or T does not play it again until you load a clip from the phone. Delete, Stop in this window, or Stop on the phone stops the audio, releases that key immediately, and unloads the clip. Mouse clicks do not stop playback. These hooks work while the window is in the background or hidden to the tray. Quitting the app (tray menu → Quit) stops them.

VoiceMeeter Setup Helper

VoiceMeeter Banana is a virtual audio mixer that lets you combine multiple audio sources (like Nvidia Broadcast + this soundboard) into one virtual microphone for Discord, Zoom, etc.

Checking for VoiceMeeter...

VoiceMeeter devices will appear in the output list below after installation.

Setup Checklist for Martin's Configuration
  1. Install VoiceMeeter Banana from the official site (button above if not detected)
  2. In VoiceMeeter Banana: set Stereo Input 1 device to Microphone (NVIDIA Broadcast)
  3. Enable B1 button (green) on both Stereo Input 1 and Voicemeeter Input strips
  4. In Mithium Sound (below): set Output Mode to "Local Device Only"
  5. Set Local Output Device to Voicemeeter Input (VB-Audio Voicemeeter VAIO)
  6. In Windows Sound Settings: set Voicemeeter Out B1 as your default microphone
  7. In Discord: leave input device on Default (no special Discord mic needed)
  8. Adjust the faders in VoiceMeeter Banana to balance your mic + soundboard levels

Home Server

Optional. Sync clips with a home-lab server on your LAN. Discord playback, local device mode, hotkeys, and the clip grid always use the library on this PC. If the server is offline, nothing blocks playback — status shows Offline and local edits stay queued for the next sync.

This is separate from LAN Web Remote, which controls this PC while it is on. The Discord bot token is never sent to the Home Server.

LAN address of the library service: http://192.168.0.211:4092.

Sent as Authorization: Bearer and X-Api-Key. Stored in settings.json, same as the bot token. Do not paste the Discord bot token here.

Sync rule: the server's revision wins. Offline edits upload on the next sync. Clips that exist only on this PC are kept. Deletes come from the sync feed, not from a row missing in the full library.
