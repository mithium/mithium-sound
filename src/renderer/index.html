How to create a Discord bot
  1. Go to the Discord Developer Portal (discord.com/developers/applications)
  2. Click New Application, give it a name, and click Create
  3. Go to the Bot tab on the left sidebar
  4. Your bot token is shown once after creation — click Copy to copy it and paste it below. If you missed it, click Reset Token to generate a new one
  5. Scroll down and enable Privileged Gateway Intents:
    • SERVER MEMBERS INTENT
    • MESSAGE CONTENT INTENT
  6. Go to OAuth2 > URL Generator on the left sidebar
  7. Under Scopes, check bot
  8. Under Bot Permissions, check Connect and Speak
  9. Copy the generated URL at the bottom and open it in your browser to invite the bot to your server

VoiceMeeter Setup Helper

VoiceMeeter Banana is a virtual audio mixer that lets you combine multiple audio sources (like Nvidia Broadcast + this soundboard) into one virtual microphone for Discord, Zoom, etc.

Checking for VoiceMeeter...

VoiceMeeter devices will appear in the output list below after installation.

Setup Checklist for Martin's Configuration
  1. Install VoiceMeeter Banana from the official site (button above if not detected)
  2. In VoiceMeeter Banana: set Stereo Input 1 device to Microphone (NVIDIA Broadcast)
  3. Enable B1 button (green) on both Stereo Input 1 and Voicemeeter Input strips
  4. In Mithium Sound (below): set Output Mode to "Local Device Only"
  5. Set Local Output Device to Voicemeeter Input (VB-Audio Voicemeeter VAIO)
  6. In Windows Sound Settings: set Voicemeeter Out B1 as your default microphone
  7. In Discord: leave input device on Default (no special Discord mic needed)
  8. Adjust the faders in VoiceMeeter Banana to balance your mic + soundboard levels
