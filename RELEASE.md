# Release & Auto-Update Workflow

This document explains how to build and publish releases for Mithium Sound with automatic updates.

## Overview

Mithium Sound uses:
- **electron-builder** for packaging (NSIS installer + portable zip)
- **electron-updater** for automatic updates via GitHub Releases
- **GitHub Releases** as the update server

## Building Releases

### Prerequisites
1. Windows machine (for native dependencies)
2. Node.js installed
3. Git configured with credentials

### Build Commands

```bash
# Install dependencies
npm install

# Build both NSIS installer and portable zip
npm run build
```

This creates in `dist/`:
- `Mithium Sound-Setup-1.7.0.exe` - NSIS installer (primary)
- `mithium-sound-1.7.0-win.zip` - Portable version (secondary)
- `latest.yml` - Update metadata (required for auto-updater)

## Publishing a Release

### 1. Update Version
Edit `package.json`:
```json
{
  "version": "1.7.0"
}
```

### 2. Commit and Tag
```bash
git add package.json
git commit -m "Bump version to 1.7.0"
git tag v1.7.0
git push origin main --tags
```

### 3. Build Artifacts
```bash
npm run build
```

### 4. Create GitHub Release

**Option A: GitHub Web UI** (Recommended)
1. Go to https://github.com/mithium/mithium-sound/releases/new
2. Tag: `v1.7.0` (must match package.json)
3. Release title: `v1.7.0` or descriptive title
4. Upload these files from `dist/`:
   - `Mithium Sound-Setup-1.7.0.exe`
   - `mithium-sound-1.7.0-win.zip`
   - `latest.yml`
5. Write release notes
6. Click "Publish release"

**Option B: GitHub CLI**
```bash
gh release create v1.7.0 \
  "dist/Mithium Sound-Setup-1.7.0.exe" \
  "dist/mithium-sound-1.7.0-win.zip" \
  "dist/latest.yml" \
  --title "v1.7.0" \
  --notes "Release notes here"
```

## Auto-Update Behavior

### For Users (Installed Version)
1. App checks for updates 5 seconds after launch
2. If update available, notification appears in Settings > Software Updates
3. User clicks "Download Update" → progress bar shows download
4. When complete, "Restart & Install" button appears
5. Click to quit and install new version

### For Developers (Dev Mode)
- Auto-update checks are **skipped** when running `npm start`
- Manual "Check for Updates" button still works in Settings

## Release Asset Requirements

For auto-updater to work, GitHub Release **must** include:

### Required Files
- `latest.yml` - Update metadata (contains version, file paths, checksums)
- `Mithium Sound-Setup-{version}.exe` - NSIS installer

### File Naming Convention
- NSIS installer: `Mithium Sound-Setup-{version}.exe`
- Portable zip: `mithium-sound-{version}-win.zip`
- Update metadata: `latest.yml`

The naming is configured in `electron-builder.yml`:
```yaml
nsis:
  artifactName: ${productName}-Setup-${version}.${ext}
```

### latest.yml Structure
Auto-generated by electron-builder. Contains:
```yaml
version: 1.7.0
files:
  - url: Mithium Sound-Setup-1.7.0.exe
    sha512: <hash>
    size: <bytes>
path: Mithium Sound-Setup-1.7.0.exe
sha512: <hash>
releaseDate: '2026-10-01T19:00:00.000Z'
```

## Troubleshooting

### Update Check Fails
- Verify GitHub Release exists with tag matching `package.json` version
- Check `latest.yml` is uploaded
- Ensure release is marked as "Release" not "Pre-release"
- Check console logs: `autoUpdater.checkForUpdates()` errors

### Update Downloads But Won't Install
- NSIS installer file must exist in release
- Check file integrity (SHA512 hash in `latest.yml`)
- Try manual download and compare file sizes

### Testing Updates Locally
1. Publish test release to GitHub (can mark as pre-release)
2. Install **previous** version of app
3. Launch app → should detect new version
4. Download and verify install works

## Security Notes

- Auto-updater verifies SHA512 checksums before installing
- Only downloads from `github.com/mithium/mithium-sound` (configured in `electron-builder.yml`)
- HTTPS enforced for all update checks
- User must manually approve download and install

## Version Numbering

Follow semantic versioning:
- **Major** (X.0.0): Breaking changes
- **Minor** (1.X.0): New features (backward-compatible)
- **Patch** (1.7.X): Bug fixes
